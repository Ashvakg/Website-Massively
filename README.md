# Website-Massively

This repository contains the source code for my personal website built using the **Massively** template by HTML5 UP. It serves as a static showcase for my professional profile, projects, and blog posts.

## Features

- **Responsive design** optimized for mobile and desktop.
- **Blog posts** section to share articles and insights.
- **Portfolio** section showcasing selected projects.
- **Contact form** enabling visitors to send messages.

## Technologies

- Pure **HTML5**, **CSS3**, and **JavaScript**.
- [Massively](https://html5up.net/massively) by **HTML5 UP** theme.

## Getting Started

To run this site locally, simply clone the repository and open `index.html` in a web browser. You can customize the content by editing the HTML files in the root directory.
